# Requests for Comments

RFCs record durable architectural proposals for this repository. They describe
the motivation, boundaries, trade-offs, and evidence required before a proposal
becomes an implementation commitment.

## Lifecycle

- **Proposed**: open for investigation and semantic changes.
- **Accepted**: the repository has committed to the direction.
- **Rejected**: evaluated but not adopted.
- **Superseded**: replaced by a later RFC, linked in both directions.

Accepted RFCs are immutable. A material change is recorded in a successor RFC
instead of rewriting the original decision.
